A funny resignation letter in a single line, for the make.fun competition [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

> I hereby resign, effective immediately. My final act as your employee is this letter, and my second final act is already on a beach somewhere.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/exit-out node main.ts
```

This writes exactly one line (142 characters, no trailing newline) to `entry.txt` in the output directory.
